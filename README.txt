Fuzzy C-Means Clustering

This code performs image clustering on grayscale images using the Fuzzy C-Means algorithm.

To execute this code, follow these steps:

         -Run the fuzzy_C_means code.
         -You can add different images, such as im3.jpeg, leon.jpeg, panda.jpg, perico.jpg, or any other image of your choice.
